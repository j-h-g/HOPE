# 实验方案

## 1. 实验目标

通过消融实验验证本文提出的**相对动作平滑掩码机制**的有效性，核心论证两条证据链：

- **机制有效**：动态障碍物掩码 + 相对动作平滑掩码的组合优于单一掩码
- **不过度约束**：掩码机制未对最终成功率和训练效率造成负面影响

## 2. 实验分组

| 实验组 | 配置 | 意义 |
|--------|------|------|
| **Full（基线）** | 无掩码 | 纯 SAC 基线，对比下界 |
| **Dyn（中间方案）** | 仅有障碍物动态掩码 | 分离动态障碍物掩码的单独贡献 |
| **Rel / Ours（最终方案）** | 动态掩码 + 相对动作平滑掩码 | 完整方案，验证时序平滑的增量价值 |

### 掩码配置说明

- **动态障碍物掩码（Dyn）**：`action_mask` 来自 LiDAR 感知的障碍物检测结果，将导致碰撞的动作概率置零
- **相对动作平滑掩码（Rel）**：在 Dyn 基础上，额外计算当前动作与上一时刻动作的转向角变化量，通过软加权方式（weight=0.3）平滑动作序列，抑制剧烈跳变
- **Full**：不做任何掩码处理，纯 SAC 输出

### 参数选择依据

相对动作平滑掩码的权重 weight=0.3 通过网格搜索确定（weight ∈ {0.1, 0.3, 0.5, 1.0}）：
- weight=0.1 过度限制动作空间，导致收敛显著变慢
- weight=1.0 等同于关闭时序约束，动作跳变与 Full 无异
- weight=0.3 在平顺度与收敛速度、最终成功率之间取得最佳平衡

## 3. 评估指标

| 指标 | 计算方式 | 物理意义 |
|------|---------|---------|
| **成功率 (SR)** | `ARRIVED episodes / 总 episodes × 100%` | 任务完成能力 |
| **回合奖励** | 单 episode 内累计奖励均值 | 整体训练质量 |
| **平顺度** | 相邻步转向角变化量绝对值的均值 `mean(|Δsteer|)` | 动作平滑程度（核心指标） |
| **效率** | `E = 10⁻⁷ × (SR/100) / T`，T 为平均步数 | 综合考量成功率与收敛速度 |

## 4. 统一训练配置

所有实验组保持以下配置完全一致，仅掩码机制不同：

| 参数 | 值 |
|------|-----|
| 随机种子 | 42（各组独立固定） |
| 最大训练步数 | 1,000,000 |
| Batch size | 8192 |
| Actor/Critic 网络 | 同 configs.py |
| 学习率 | 同 configs.py |
| 场景采样 | SceneChoose（Normal/Complex/Extrem/DLP） |
| 评估间隔 | 每 2000 episodes 保存一次模型 |

## 5. 场景设置

训练与评估均覆盖四种场景：

| 场景 | 难度 | 目标成功率 |
|------|------|-----------|
| Normal | 简单 | ≥ 95% |
| Complex | 中等 | ≥ 95% |
| Extreme | 困难 | ≥ 90% |
| DLP | 极限泊车位 | ≥ 99% |

## 6. 实验记录

每个实验组独立保存以下数据：

```
log/exp/
├── full_{timestamp}/        # Full 组
│   ├── SAC_best.pt          # 最佳模型
│   ├── configs.txt          # 配置文件快照
│   ├── reward.png           # 训练奖励曲线
│   ├── tensorboard/         # Scalar 日志（供后续绘图）
├── dyn_{timestamp}/          # Dyn 组
│   └── ...
└── rel_{timestamp}/          # Rel (Ours) 组
    └── ...
```

TensorBoard 需额外记录：
- `avg_steer_change`：每个 episode 内的平均转向角跳变量
- `avg_speed_change`：每个 episode 内的平均速度跳变量
- 各场景分项成功率（Normal / Complex / Extreme / DLP）

### 预期结论

| 对比项 | 预期结果 | 对应论证 |
|--------|---------|---------|
| SR：Rel ≥ Dyn ≥ Full | Rel 成功率不低于 Dyn/Full | 掩码未伤害任务能力 |
| 奖励：Rel ≥ Dyn ≥ Full | Rel 最终奖励最优 | 掩码带来正向增益 |
| 平顺度：Rel < Dyn < Full | Rel 动作最平滑 | 时序掩码机制有效 |
| 效率：Rel ≥ Dyn ≥ Full | Rel 综合效率最高 | 平滑约束不拖累训练 |
